Flashies support

Flashies helps you turn notes into flashcards and keep up with daily review.

Start a library

In Library, create a module for a subject and add a chapter. Inside the chapter, use + to import CSV or Markdown files or create a card by hand. Add a Sample Module if you want to try the app first.

Review cards

The Review tab shows new and due cards. Reveal the answer before grading it. Got It schedules the next review further ahead; Again brings the card back in ten minutes. To study ahead, open a chapter and choose Study All.

Back up or restore

Open a module, tap More, then Export Module to save a .flashiesmodule backup. Restore it with Library → + → Import Module. Chapter files use .flashies and are imported inside a module. Imports create copies and let you keep progress or start fresh.

Local storage and reminders

Your library is stored on this device. To move study material to another device, export a chapter or module, share the file and import it there. Daily reminders are configured in Flashies Settings; notification permission is controlled in iOS Settings.

Report an issue

Include your device model, iOS version, Flashies version and the steps that caused the issue. A screenshot can help. Do not send passwords or private card content.
